# TC-05 多协议集群同时支持两种请求

## 用例编号与名称

TC-05 多协议集群同时支持两种请求

## 所属场景

SC06 Claude 协议支持

## 版本声明

- `bfe`：当前源码版本

## 测试目的

验证 `ModelProtocols` 同时包含 `openai` 与 `anthropic` 的集群能够按请求风格选择正确的 key 与头部。

## 运行模式

单组件模式：仅启动真实 `bfe` 进程。

## 前置条件

1. 已编译 `bfe` 可执行文件。
2. mock 后端 `cluster_both_protocols` 已启动，返回 200。
3. 临时 BFE 配置已生成并加载，`cluster_both_protocols` 配置 `ModelProtocols = ["openai", "anthropic"]`，配置两把 key。
4. `ai_route.data` 中 `apikey_ak_user_a` 命中 `user_a-both`，target 为 `cluster_both_protocols`。

## 配置构造

- `cluster_both_protocols.AIConf`：
  - `ModelProtocols`: `["openai", "anthropic"]`
  - `Keys`:
    - `{"Name":"both-openai-key","Key":"sk-both-openai-key","Weight":50}`
    - `{"Name":"both-anthropic-key","Key":"sk-both-anthropic-key","Weight":50}`

## BFE 请求

向 `both.example.org` 连续发送 2 次 POST 请求：

1. OpenAI 风格：
   - Path: `/v1/chat/completions`
   - Authorization: `Bearer ak_user_a`
   - Body: `{"model":"gpt-4"}`

2. Anthropic 风格：
   - Path: `/v1/messages`
   - x-api-key: `ak_user_a`
   - Body: `{"model":"claude-3-5-sonnet","messages":[{"role":"user","content":"hi"}]}`

## 预期结果

- 两个请求均返回 200。
- `cluster_both_protocols` mock backend 命中 2 次。
- OpenAI 请求 upstream 收到 `Authorization: Bearer sk-both-openai-key`（或对应 Anthropic key 以 Bearer 形式注入，取决于加权随机选中的 key）。
- Anthropic 请求 upstream 收到 `x-api-key: sk-both-anthropic-key` 与 `anthropic-version: 2023-06-01`。

> 说明：由于加权随机选 key，断言策略为“存在符合协议风格的 header 即可”，不强制固定某一把 key。

## 清理

停止 `bfe` 进程、mock 后端，删除临时目录。
